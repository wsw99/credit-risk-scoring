# Stage 2: 经典银行评分卡 — 报告

> 生成日期: 2026-05-20
> 数据: LendingClub 2007-2018, Train 2007-2014 / Val 2015 / Test 2016

---

## 1. 概述

### 1.1 Stage 2 做什么

Stage 1 在原始数值特征上跑了一个 Logistic Regression（AUC 0.714）。**Stage 2 的目标不同**：不是追求最高 AUC，而是构建一个**能被银行风控部门、监管机构、贷款申请人三方都理解的评分卡**。

核心思路：把连续特征切成有意义的区间（分箱），每个区间赋予一个权重值（WOE），最终把所有特征的分数加减得到 300-850 的信用分。

### 1.2 与 Stage 1 的本质区别

| | Stage 1 (Raw LR) | Stage 2 (WOE Scorecard) |
|---|---|---|
| **输入** | 原始数值 (loan_amnt=$12,000) | WOE 编码值 (loan_amnt_WOE=+0.32) |
| **模型** | LR on raw features | LR on WOE features |
| **可解释性** | "利率高 1%，log-odds 增加 0.03" | "利率 > 14.48% 扣 11.7 分" |
| **缺失值** | 需要填补 | 天然作为独立 bin |
| **非线性** | 需要手动特征工程 | WOE 分箱自动处理 |
| **监管认可** | 低 | 高（Basel II/III, FCA, OCC 认可） |

## 2. 方法论

### 2.1 Pipeline 流程

```
84 个特征
   │
   ▼
┌─────────────────────────────────┐
│ Step 1: WOE 分箱 (optbinning)   │
│ - 每个特征最优切分成 ≤8 个区间   │
│ - 约束: 单调趋势 (坏账率单调递增)│
│ - 缺失值 → 独立 bin              │
│ - 14 个特征无法分箱 → 自动移除   │
└──────────────┬──────────────────┘
               ▼
┌─────────────────────────────────┐
│ Step 2: IV 筛选                 │
│ - IV = Σ (好% - 坏%) × WOE      │
│ - IV < 0.01 → 无预测力 → 移除   │
│ - 保留 39 个，移除 31 个         │
└──────────────┬──────────────────┘
               ▼
┌─────────────────────────────────┐
│ Step 3: WOE 编码                │
│ - 用 train 的分箱边界            │
│ - 将 raw value → WOE value       │
│ - train/val/test 分别转换         │
└──────────────┬──────────────────┘
               ▼
┌─────────────────────────────────┐
│ Step 4: VIF + 相关性筛选         │
│ - VIF > 5 → 多重共线性 → 移除    │
│ - |corr| > 0.7 → 保留 IV 更高的  │
│ - 34 → 31 个最终特征             │
└──────────────┬──────────────────┘
               ▼
┌─────────────────────────────────┐
│ Step 5: Logistic Regression     │
│ - sklearn, L2 正则化, C=1.0     │
│ - 31 个 WOE 特征 + 截距          │
└──────────────┬──────────────────┘
               ▼
┌─────────────────────────────────┐
│ Step 6: 分数刻度化               │
│ - base_score=600, base_odds=50:1 │
│ - PDO=20 (odds 翻倍 → +20 分)   │
│ - Score = 487 + 28.85×ln(好:坏) │
└──────────────┬──────────────────┘
               ▼
         评分卡表 + 分数
```

### 2.2 WOE 分箱原理

**WOE (Weight of Evidence)** = ln(该区间好人占比 / 坏人占比)。正值表示好人多于坏人（低风险），负值表示坏人更多（高风险）。

以 `int_rate` (利率) 为例：

| 区间 | 样本数 | 违约率 | WOE | 含义 |
|---|---|---|---|---|
| < 9.74% | 91,014 | 6.1% | +1.14 | 好人是坏人的 3.1 倍 |
| 9.74% - 14.48% | 175,911 | 13.4% | +0.28 | 略偏好人 |
| > 14.48% | 184,135 | 25.7% | -0.53 | 坏人显著偏多 |

WOE 把"利率从 9.74% 升到 14.48%"这个非线性变化，转化成了 WOE 值从 +1.14 到 -0.53 的线性变化，LR 可以直接拟合。

### 2.3 数据排除策略

**排除 grade 和 sub_grade**：这两个是 LendingClub 的内部评级——相当于用 LendingClub 自己的评分卡来预测 LendingClub 的违约。在真实银行场景中，你没有对手的内部评级可用。排除它们让 Stage 2 展示的是**纯自有数据的建模能力**。

## 3. 模型结果

### 3.1 核心指标

| 指标 | Train | Val | Test | 说明 |
|---|---|---|---|---|
| **AUC** | 0.6995 | 0.7294 | **0.7046** | 区分能力 |
| **KS** | 0.2892 | 0.3323 | **0.2957** | 最大区分度 |
| **Gini** | 0.3989 | 0.4588 | **0.4091** | 2×AUC - 1 |
| **PSI (vs Train)** | — | 0.0158 | **0.0097** | 时间稳定性 |
| **违约率** | 17.0% | 20.2% | 23.3% | 逐年上升 |
| **特征数** | — | — | **31** | 最终评分卡 |

### 3.2 与 Stage 1 对比

| 指标 | Stage 1 (Raw LR) | Stage 2 (WOE Scorecard) | 变化 |
|---|---|---|---|
| Test AUC | 0.7140 | 0.7046 | -0.0094 |
| Test KS | — | 0.2957 | 新增 |
| 特征数 | 89 | 31 | -65% |
| 可解释性 | 低 | 高（每 bin 有分数） | 质的提升 |
| PSI 监控 | 无 | 0.0097 (稳定) | 新增 |

**AUC 下降 0.0094 的解释**：WOE 分箱将连续值离散化，丢失了精细的数值差异。这就像把"收入 $52,340 → $53,120"的细微变化变成了"中等收入 bin → 中等收入 bin"的无变化。**0.01 的 AUC 是购买可解释性的代价。**

### 3.3 PSI 时间稳定性

PSI (Population Stability Index) 衡量 Train 和 Test 之间分数分布的变化：

| PSI 值 | 含义 |
|---|---|
| < 0.1 | 稳定，无需调整 |
| 0.1-0.2 | 中等漂移，建议调查 |
| > 0.2 | 显著漂移，模型可能失效 |

**本模型 PSI = 0.0097**，属于极稳定范围。尽管 Test 违约率 (23.3%) 明显高于 Train (17.0%)，但评分卡通过 WOE 编码保持了分数分布的稳定。

## 4. 评分卡解读

### 4.1 分数刻度

| 参数 | 值 | 含义 |
|---|---|---|
| Base Score | 600 | 在 base odds 下的分数 |
| Base Odds | 50:1 | 50 个好人对 1 个坏人 |
| PDO | 20 | odds 翻倍 → 分数 +20 |
| Factor | 28.85 | PDO / ln(2) |
| Offset | 487.12 | base_score - factor × ln(base_odds) |

**分数公式**：Score = 487.12 + 28.85 × ln(好:坏赔率)

```
分数  赔率 (好:坏)   违约率     解读
────  ────────────  ────────   ──────────
650   256:1         0.4%      极低风险
600    50:1          2.0%      基准线
550    9.8:1         9.3%      略高风险
500    1.9:1        34.5%      高风险
450    0.37:1       73.0%      极高风险
```

### 4.2 分数分布

| 统计量 | Train | Val | Test |
|---|---|---|---|
| 均值 | 535.1 | 537.9 | 537.8 |
| 中位数 | 533.1 | 536.5 | 536.0 |
| P5 | 498.3 | 498.6 | 500.8 |
| P95 | 573.4 | 574.9 | 574.1 |
| 最小值 | 471.0 | 470.4 | 471.0 |
| 最大值 | 613.6 | 614.0 | 614.8 |

Train、Val、Test 三组分数的均值和分布高度一致，PSI 仅 0.0097，说明评分卡在时间上非常稳定。

### 4.3 分数段违约率 (Test Set)

## 6. 关键发现

### 6.1 最强预测因子

`int_rate` 是压倒性的最强特征（IV=0.675），远超第二名。这符合直觉——LendingClub 自己也是根据风险定价的。但注意：Stage 2 **没有使用** LendingClub 的内部评级 grade/sub_grade，完全依赖客观特征。

### 6.2 时间稳定性优异

PSI = 0.0097 表明评分卡在 2007-2014（Train）和 2016（Test）之间极其稳定。虽然 Test 违约率 (23.3%) 高于 Train (17.0%)——反映 LendingClub 后期放宽了信贷标准——但 WOE 编码吸收了这部分宏观漂移，评分卡本身不需要重新校准。

### 6.3 特征压缩效果显著

从 84 个特征压缩到 31 个（-63%），模型复杂度大幅降低，AUC 仅损失 0.0094（-1.3%）。这说明：
- 一半以上的特征几乎没有独立预测力
- 剩余特征之间存在大量冗余
- 31 个特征足够覆盖主要风险维度

### 6.4 残余风险

| 风险 | 说明 |
|---|---|
| **幸存者偏差** | 训练数据只有获批贷款，被拒申请人的特征不在数据中 |
| **分数范围偏窄** | [471, 615] 而非标准的 [300, 850]，因为 LR 概率估计保守 |
| **未使用 grade** | 排除了 LendingClub 最强的内部评级特征（在真实银行场景不可用） |

## 7. 与社区对比

| 来源 | 方法 | AUC | KS | 备注 |
|---|---|---|---|---|
| **本项目 Stage 2** | WOE + LR, 时间切分 | 0.705 | 0.296 | 31 特征, 无 grade |
| 本项目 Stage 1 | Raw LR, 时间切分 | 0.714 | — | 89 特征 |
| sjagannathan17 | LR + XGBoost, 随机 CV | 0.78 / 0.80 | — | 随机切分，AUC 偏高 |
| 典型银行评分卡 | WOE + 逐步 LR | 0.70-0.75 | 0.25-0.35 | 行业基准 |

**结论**：AUC 0.705 / KS 0.296 处于时间切分下 WOE 评分卡的合理范围，低于随机 CV 的结果（0.78+）是因为时间切分更真实地模拟了"用过去预测未来"。
