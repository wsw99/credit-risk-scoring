# Stage 2: 经典银行评分卡 — 报告

> 生成日期: 2026-05-21
> 数据: LendingClub 2007-2018, Train 2007-2014 / Val 2015 / Test 2016

---

## 1. 概述

### 1.1 Stage 2 做什么

Stage 1 在 62 个原始数值特征上跑了一个 Logistic Regression（AUC 0.711）。**Stage 2 的目标不同**：不是追求最高 AUC，而是构建一个**能被银行风控部门、监管机构、贷款申请人三方都理解的评分卡**。

核心思路：把连续特征切成有意义的区间（分箱），每个区间赋予一个权重值（WOE），最终把所有特征的分数加减得到 300-850 的信用分。

### 1.2 与 Stage 1 的本质区别

| | Stage 1 (Raw LR) | Stage 2 (WOE Scorecard) |
|---|---|---|
| **输入** | 原始数值 (loan_amnt=$12,000) | WOE 编码值 (loan_amnt_WOE=+0.23) |
| **模型** | LR on raw features | LR on WOE features |
| **可解释性** | "利率高 1%，log-odds 增加 0.03" | "利率 < 9.74% 加 15.8 分" |
| **缺失值** | 需要填补 | 天然作为独立 bin |
| **非线性** | 需要手动特征工程 | WOE 分箱自动处理 |
| **监管认可** | 低 | 高（Basel II/III, FCA, OCC 认可） |

### 2.2 WOE 分箱原理

**WOE (Weight of Evidence)** = ln(该区间好人占比 / 坏人占比)。正值表示好人多于坏人（低风险），负值表示坏人更多（高风险）。

以 `int_rate` (利率) 为例：

| 区间 | 样本数 | 违约率 | WOE | 含义 |
|---|---|---|---|---|
| < 9.74% | 91,014 | 6.1% | +1.14 | 好人是坏人的 3.1 倍 |
| 9.74% - 14.48% | 175,911 | 13.4% | +0.28 | 略偏好人 |
| > 14.48% | 184,135 | 25.7% | -0.53 | 坏人显著偏多 |

WOE 把"利率从 9.74% 升到 14.48%"这个非线性变化，转化成了 WOE 值从 +1.14 到 -0.53 的线性变化，LR 可以直接拟合。

### 2.3 分箱后统计验证

IV 筛选后，对保留的 34 个特征进行两项额外验证：

**相邻 bin 卡方合并检验**：对每个特征相邻的两个 bin 做 2×2 卡方独立性检验。如果 p > 0.05，说明两组违约率差异不显著，bin 切得过细——应合并。

| 指标 | 结果 |
|---|---|
| 总检验对数 | ~90 |
| 需合并 | 1 对（1.1%） |

| 特征 | 相邻 bin | p 值 | 违约率 A | 违约率 B |
|---|---|---|---|---|
| `verification_status` | Source Verified vs Verified | 0.505 | 18.8% | 18.9% |

仅 1 对 bin 有问题（1.1%），整体分箱质量良好，暂不强制合并。

**WOE 趋势一致性检验**：用 Train 的分箱边界计算 Val 上的 WOE，比对 Train vs Val 的 WOE 向量相关性。34 个 IV-pass 特征全部通过——Train/Val WOE 相关性和符号方向一致，特征在时间上表现稳定。

### 2.4 数据清洗与特征排除

Stage 2 的数据在 Stage 1 清洗基础上额外经历了 **per-split NaN/常数检测**：14 个 LendingClub 2015 年后新增的字段（如 `open_acc_6m`, `il_util`, `total_cu_tl` 等）在 Train (2007-2014) 中 100% 为 NaN，虽然在全局检查中 NaN 率约 73%（因 Val/Test 有值）逃过了全局 80% 阈值，但经过逐 split 检查后被全部剔除。

最终进入 Stage 2 的特征：68 列 → 排除 `is_bad`, `issue_year`, `loan_status`, `addr_state`, `grade`, `sub_grade` → **62 个候选特征全部分箱成功**。

**排除 grade 和 sub_grade**：这两个是 LendingClub 的内部评级——相当于用 LendingClub 自己的评分卡来预测 LendingClub 的违约。在真实银行场景中，你没有对手的内部评级可用。排除它们让 Stage 2 展示的是**纯自有数据的建模能力**。

### 3.3 AUC 差距归因分析

为了精准定位 Stage 2 AUC 下降的原因，在同一条 test 集上做了消融实验：

| 实验 | 特征数 | 编码方式 | Test AUC | Δ vs Stage 1 |
|---|---|---|---|---|
| A. Stage 1 Raw LR | 62 | 原始值 + 标准化 | **0.7108** | (baseline) |
| B. Raw LR (仅保留 Stage 2 的 26 个特征) | 26 | 原始值 + 标准化 | 0.7086 | -0.0022 |
| C. Stage 2 WOE Scorecard | 26 | WOE 分箱 + LR | 0.7040 | -0.0068 |

**差距拆解**：

```
Stage 1 (0.7108)
    │
    ├── 特征筛选 (62 → 26):    -0.0022  (仅 32% 的总损失)
    │    ├─ funded_amnt, loan_amnt 与 funded_amnt_inv 高度相关 (corr≈0.99)
    │    ├─ fico_range_low 与 fico_range_high 高度相关 (corr≈0.98)
    │    └─ 被 VIF/相关性过滤器正确识别为冗余特征 → 损失极小 ✓
    │
    ├── WOE 离散化 (raw → bins): -0.0046  (68% 的总损失)  ← 主要原因
    │    └─ 连续值被切成 3-6 个 bin 后丢失了精细的数值差异
    │
    ▼
Stage 2 (0.7040)
```

**结论**：AUC 下降的主要原因是 **WOE 分箱的离散化损失**（-0.0046），而非特征筛选。特征筛选只损失了 0.0022，说明 VIF/相关性过滤正确识别了冗余特征——被移除的 `funded_amnt`、`loan_amnt`、`fico_range_low` 等虽然个体预测力强，但与保留特征几乎完全共线。

### 3.4 为什么连续值 + NaN 填补能赢 WOE 分箱？

一个常见的疑问：Stage 1 的数据有大量 NaN（中位数填补后喂给 LR），Stage 2 不仅做了更严格的清洗还用了更精细的 WOE 编码——为什么反而 AUC 更低？

答案在于 **LR 和 WOE 使用数值信息的方式根本不同**。

**Stage 1 的 LR 在连续值上做了什么**：中位数填补后，每个特征保留了几百到几千个唯一值。比如 `int_rate` 有 1,300+ 个不同的利率值（5.32%, 5.33%, 5.34%...）。LR 学习的是一个连续函数：利率每升高 1 个基点，log-odds 变化一个微小量。NaN 被中位数替代后只是变成了"普通值"，不破坏函数的连续性。**连续值给了 LR 最大的信息自由度来拟合训练数据的模式。**

**Stage 2 的 WOE 分箱做了什么**：同一列 `int_rate` 被切成 3 个 bin（<9.74%, 9.74-14.48%, >14.48%）。现在 LR 只能看到 3 个不同的 WOE 值（+1.14, +0.28, -0.53）。5.32% 和 9.73% 的利率在这个世界里**完全相同**。任何需要精细区分的模式都被抹掉了。

```
信息量的降维（以 int_rate 为例）：
  Stage 1 连续值:  [5.32, 5.33, 5.34, ..., 30.99]  → 1,300+ 个信号
  Stage 2 WOE 分箱:  [低, 中, 高]                    → 3 个信号
```

这就是 -0.0046 的本质来源：**把连续函数的 1,300+ 个自由度硬压成 3 个。** 不是 NaN 的问题，不是过拟合的问题——就是信息压缩的代价。

**那为什么银行还要用 WOE？** 因为 1,300 个信号组成的函数虽然更准确，但无法向监管解释"为什么利率 12.34% 和 12.35% 差 0.03 分"。监管（Basel II/III, FCA, OCC）要求评分卡必须是**分段常数**的——每个特征切成有限的几段，每段给出明确的风险权重。WOE 分箱 + LR 是目前唯一同时满足统计合理性和监管可解释性的方法。

简言之：**0.0068 的 AUC 不是模型的失败，是故意的设计取舍。**

### 3.5 PSI 时间稳定性

PSI (Population Stability Index) 衡量 Train 和 Test 之间分数分布的变化：

| PSI 值 | 含义 |
|---|---|
| < 0.1 | 稳定，无需调整 |
| 0.1-0.2 | 中等漂移，建议调查 |
| > 0.2 | 显著漂移，模型可能失效 |

**本模型 PSI (Train vs Test) = 0.0101**，属于极稳定范围。尽管 Test 违约率 (23.3%) 明显高于 Train (17.0%)，但评分卡通过 WOE 编码保持了分数分布的稳定。

## 4. 评分卡解读

### 4.1 分数刻度

| 参数 | 值 | 含义 |
|---|---|---|
| Base Score | 600 | 在 base odds 下的分数 |
| Base Odds | 50:1 | 50 个好人对 1 个坏人 |
| PDO | 20 | odds 翻倍 → 分数 +20 |
| Factor | 28.85 | PDO / ln(2) |
| Offset | 487.12 | base_score - factor × ln(base_odds) |

**分数公式**：Score = 487.12 + 28.85 × ln(好:坏赔率)

```
分数  赔率 (好:坏)   违约率     解读
────  ────────────  ────────   ──────────
650   256:1         0.4%      极低风险
600    50:1          2.0%      基准线
550    9.8:1         9.3%      略高风险
500    1.9:1        34.5%      高风险
450    0.37:1       73.0%      极高风险
```

Train、Val、Test 三组分数的均值和分布高度一致，PSI 仅 0.0094-0.0101，说明评分卡在时间上非常稳定。

## 6. 关键发现

### 6.1 最强预测因子

`int_rate` 是压倒性的最强特征（IV=0.675），但值得注意的是 `term`（贷款期限）以 importance=0.291 排名第二——长期限（60 month）比短期（36 month）多扣 20.4 分。这两个特征合计贡献了整个评分卡约 53% 的预测力。注意：Stage 2 **没有使用** LendingClub 的内部评级 grade/sub_grade，完全依赖客观特征。

### 6.2 时间稳定性优异

PSI = 0.0101 (Train vs Test) 表明评分卡在 2007-2014（Train）和 2016（Test）之间极其稳定。虽然 Test 违约率 (23.3%) 高于 Train (17.0%)——反映 LendingClub 后期放宽了信贷标准——但 WOE 编码吸收了这部分宏观漂移，评分卡本身不需要重新校准。WOE 一致性检验也确认了 34 个 IV-pass 特征在 Train/Val 之间 WOE 方向一致。

### 6.3 特征压缩效果显著

从 62 个候选特征压缩到 26 个（-58%），模型复杂度大幅降低，但特征筛选仅损失 AUC 0.0022（占总损失的 32%）。消融实验证明：
- VIF/相关性过滤正确识别了冗余特征（如 `funded_amnt` 与 `funded_amnt_inv` 相关系数 ~0.99）
- WOE 离散化是 AUC 下降的主要原因（-0.0046，占 68%）
- 26 个特征足够覆盖主要风险维度

### 6.4 残余风险

| 风险 | 说明 |
|---|---|
| **幸存者偏差** | 训练数据只有获批贷款，被拒申请人的特征不在数据中 |
| **分数范围偏窄** | [473, 614] 而非标准的 [300, 850]，因为 LR 概率估计保守 |
| **未使用 grade** | 排除了 LendingClub 最强的内部评级特征（在真实银行场景不可用） |
| **AUC 略低于 Stage 1** | WOE 离散化 (-0.0046) + 特征筛选 (-0.0022) = 共损失 0.0068 |

## 7. 与社区对比

| 来源 | 方法 | AUC | KS | 备注 |
|---|---|---|---|---|
| **本项目 Stage 2** | WOE + LR, 时间切分 | 0.704 | 0.295 | 26 特征, WOE 编码, 无 grade |
| 本项目 Stage 1 | Raw LR, 时间切分 | 0.711 | — | 62 特征, 原始值 |
| sjagannathan17 | LR + XGBoost, 随机 CV | 0.78 / 0.80 | — | 随机切分，AUC 偏高 |
| 典型银行评分卡 | WOE + 逐步 LR | 0.70-0.75 | 0.25-0.35 | 行业基准 |

**结论**：AUC 0.704 / KS 0.295 处于时间切分下 WOE 评分卡的合理范围，低于随机 CV 的结果（0.78+）是因为时间切分更真实地模拟了"用过去预测未来"。
